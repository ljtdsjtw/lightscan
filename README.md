# 轻扫码

一个独立的 Mac 二维码小工具，无需 Raycast、uTools 或额外插件。识别使用系统自带的 Apple Vision，在本机离线进行。

## 打开使用

从 [Releases 下载轻扫码](https://github.com/ljtdsjtw/lightscan/releases/latest) 的应用压缩包，解压后双击 `轻扫码.app`。预编译版本适用于 Apple Silicon Mac、macOS 13 或更高版本。

也可以下载源码，运行 `bash build.sh`，然后打开 `dist/轻扫码.app`。

- **框选屏幕扫码**：点击蓝色按钮，或按 **⌥⇧Q（Option + Shift + Q）**，拖动鼠标框住二维码；Esc 取消。
- **选择图片**：读取 PNG、JPEG 等图片中的二维码。
- **识别剪贴板图片**：先复制图片，再点击按钮。也支持 Finder 中复制的图片文件。

识别成功后自动将内容复制为文本。一次有多个二维码时，通过下拉框选择；重复内容会合并。网页链接可以点击“打开链接”手动打开。应用不会自动跳转网址。

关闭窗口后，应用仍在菜单栏，点击二维码图标即可再次操作。按 ⌘Q 或菜单栏的“退出”完全退出应用。

## 首次屏幕扫码

macOS 会要求屏幕录制权限。到 **系统设置 → 隐私与安全性 → 屏幕与系统音频录制（旧版系统称“屏幕录制”）**，允许“轻扫码”，并按系统提示退出、重新打开应用。

图片和剪贴板扫码无需屏幕录制权限。全局快捷键无需辅助功能权限。如 ⌥⇧Q 被其他软件占用，请使用窗口按钮或菜单栏。

## 安装与数据

可选：将解压或编译得到的 `轻扫码.app` 拖入“应用程序”文件夹，再从那里打开。建议在授权屏幕录制前选定应用存放位置。

无需登录、订阅或联网。不上传图片，不写入识别历史。框选截图临时存入独立的私有临时目录，识别后删除。识别结果只留在应用内存和系统剪贴板里；你使用的剪贴板历史工具可能自行保留副本。点击“打开链接”会通过默认浏览器访问对应网址。

应用使用临时签名，尚未经过 Apple 公证。未添加开机启动，不修改系统设置。

## 系统与源码

当前打包版本适用于 **Apple Silicon Mac、macOS 13 或更高版本**。

使用系统 Command Line Tools 编译，无第三方依赖：

```sh
bash build.sh
bash test.sh
```

`Sources/Scanner.swift` 为识别逻辑；`Sources/main.swift` 为原生 AppKit 界面、快捷键和屏幕框选；`Sources/MakeIcon.swift` 生成应用图标。

测试覆盖网址、中文、Emoji、Wi-Fi 配置、多行文本、多二维码、去重、无二维码、损坏图片，以及链接按钮的协议判断。录屏授权与跨应用快捷键还需要在实际桌面环境中验证。
